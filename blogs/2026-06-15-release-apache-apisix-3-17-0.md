Apache APISIX 3.17.0 ships with AI Gateway expansion (Amazon Bedrock support, Anthropic Messages API, OpenAI Responses API, and a max_stream_duration_ms safeguard), new authentication plugins (saml-auth, dingtalk-auth, feishu-auth, acl), and GraphQL tooling (graphql-limit-count, graphql-proxy-cache). It also adds data protection plugins (data-mask, error-page, oas-validator, exit-transformer) plus breaking changes including stricter auth defaults across jwt-auth, key-auth, and hmac-auth and authentication now required for Admin schema validation.
